How to read the output

  • The model returns one probability-like score between 0 and 1.
  • Scores above {{ model.threshold }} are classified as class 1 (elevated model-indicated risk).
  • The score is a model output, not a clinically validated risk percentage.
  • It is not a diagnosis and must be interpreted by a qualified clinician.
