Project overview

Heart Attack Risk Prediction System

A Flask web application that makes an existing LSTM deep learning classifier usable through a clean, validated clinical-data form, with saved results, history, charts and downloadable reports.

Objectives

  • Serve the trained model through a reliable web interface.
  • Preserve the original preprocessing, feature order and 0.5 threshold.
  • Validate every input before inference.
  • Keep an auditable, local history of predictions.

Technology stack

PythonFlaskTensorFlow / Keras scikit-learnPandasNumPy SQLiteBootstrap 5Chart.js Gunicorn

Responsible use & privacy

Research tool only

Outputs are experimental. They are not diagnoses, and this software is not a medical device.

Local data storage

Entries and predictions are saved in a local SQLite database. Hosted instances may use ephemeral storage, see the README.

No fabricated metrics

The app shows no accuracy figures because none were supplied with the model artifacts.
